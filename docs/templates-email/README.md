# Templates de e-mail do login (Supabase → Authentication → Emails)

Cole cada arquivo no template correspondente do painel do Supabase. Os e-mails saem pelo SMTP do Resend (`nao-responda@mail.evoque.global`).

| Template no Supabase | Assunto | Arquivo |
|---|---|---|
| Confirm signup | Confirme seu e-mail | `confirmar-cadastro.html` |
| Invite user | Você foi convidado | `convite.html` |
| Magic link | Seu link para entrar | `link-magico.html` |
| Reset password | Criar nova senha | `trocar-senha.html` |
| Change email address | Confirme seu novo e-mail | `trocar-email.html` |
| Reauthentication | Seu código de verificação | `codigo-verificacao.html` |
